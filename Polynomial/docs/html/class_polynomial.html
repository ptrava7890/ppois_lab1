Подробное описание

Многочлен с вещественными коэффициентами.

Коэффициент с индексом i стоит при x в степени i. Например, Polynomial{2, -3, 1} задаёт x² − 3x + 2. Старшие нули удаляются. Для нулевого многочлена по соглашению степень равна 0.
